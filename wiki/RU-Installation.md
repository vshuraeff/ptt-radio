# Установка

Выполнив шаги с этой страницы, вы установите мод, распакуете компаньон на свой компьютер и настроите запуск игры с флагом, который нужен рации.

Для работы нужны три вещи:

- мод на сервере **и** в игре у каждого игрока. Это не клиентский мод, да и Factorio не пустит на сервер с другим набором модов;
- компаньон у каждого игрока, на том же компьютере, где запущена игра;
- игра, запущенная с флагом `--enable-lua-udp <порт>`: через него мод общается с компаньоном.

Для мода нужна Factorio 2.1. Что нужно серверу, описано в разделе [Настройка сервера](RU-Server-Setup).

## 1. Поставьте мод

**С портала модов.** В игре откройте «Моды», найдите *PTT Radio*, установите и перезапустите игру. Если мод уже стоит на сервере, игра сама предложит его скачать при подключении.

**Из zip-архива.**

1. Скачайте `ptt-radio_<версия>.zip` со [страницы релизов](https://github.com/vshuraeff/ptt-radio/releases).
2. Положите архив как есть, не распаковывая, в папку `mods` игры:
   - Windows: `%APPDATA%\Factorio\mods`
   - macOS: `~/Library/Application Support/factorio/mods`
   - Linux: `~/.factorio/mods`
3. Запустите игру и проверьте в «Модах», что *PTT Radio* включён.

## 2. Установите компаньон

На macOS или Linux выполните в Терминале:

```sh
curl -fsSL https://github.com/vshuraeff/ptt-radio/releases/latest/download/install.sh | sh
```

На Windows x86_64 выполните в PowerShell 5.1 или новее:

```powershell
irm https://github.com/vshuraeff/ptt-radio/releases/latest/download/install.ps1 | iex
```

Установщик скачивает последний релиз, сверяет его контрольную сумму SHA-256 и ставит компаньон в папку `ptt-radio-companion` внутри папки пользовательских данных Factorio — там же, где лежит папка `mods` из списка выше. В конце он печатает команду запуска компаньона и строку для параметров запуска Steam. Права администратора ему не нужны, настройки Steam он не трогает. Чтобы обновить компаньон, выполните команду ещё раз: если загрузка, проверка контрольной суммы или архива не пройдёт, прежняя установка останется на месте.

Чтобы указать свои папки или закрепить версию, сначала скачайте установщик, а потом запустите его с параметрами:

```sh
curl -fsSLo install.sh https://github.com/vshuraeff/ptt-radio/releases/latest/download/install.sh
sh install.sh --factorio-dir "/path/to/Factorio data" --mods-dir "/path/to/custom mods" --version v0.4.1
```

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/vshuraeff/ptt-radio/releases/latest/download/install.ps1 -OutFile install.ps1
& .\install.ps1 -FactorioDir 'D:\Games\Factorio data' -ModsDir 'D:\Games\custom mods' -Version v0.4.1
```

`--mods-dir` / `-ModsDir` записывает в `install.json` абсолютный путь к папке модов; саму эту папку и `mod-list.json` установщик не трогает. Без этого параметра используется `<папка данных Factorio>/mods`. Установленный компаньон удаляет свою папку, когда мод пропадает, только если записана именно `<папка данных Factorio>/mods`; если передать в `--mods-dir` эту же папку или ссылку на неё, удаление тоже работает. С любой другой папкой компаньон себя не удаляет и остаётся, пока вы не удалите его сами. Остальные условия — в разделе [Удаление вместе с модом](RU-Companion#удаление-вместе-с-модом).

`--version` / `-Version` выбирает только то, какой релиз поставит установщик. Сборки компаньона со страницы релизов при каждом запуске проверяют последний релиз на GitHub. Если это стабильный релиз и он новее запущенной версии, компаньон скачивает и проверяет его, заменяет собственный исполняемый файл (мод при этом не обновляется) и перезапускается с теми же аргументами — после этого он уже не совпадает с закреплённой версией мода. Если проверка не удалась, остаётся текущая версия. Чтобы остаться на выбранной версии, запускайте компаньон с `--no-self-update` или задайте `PTT_RADIO_NO_SELF_UPDATE=1` (годится любое значение, кроме пустого и `0`). В строке для Steam, которую печатает установщик, этого флага нет. Ставьте его перед `--launch`: всё, что идёт после `--launch`, передаётся игре. Например: `"<папка данных Factorio>/ptt-radio-companion/ptt-radio-companion" --no-self-update --launch %command%`.

Архивы для Linux пока есть только для x86_64 с glibc 2.35 и новее; на macOS поддерживаются Apple silicon и Intel. На других платформах установщик останавливается с ошибкой: архив компаньона для них не выпускается.

### Ручная загрузка

1. На [странице релизов](https://github.com/vshuraeff/ptt-radio/releases) скачайте файл для своей системы:

   | Система | Файл |
   | --- | --- |
   | Windows (64 бит) | `ptt-radio-companion-<версия>-windows-x86_64.zip` |
   | macOS (Apple silicon и Intel) | `ptt-radio-companion-<версия>-macos-universal.zip` |
   | Linux (x86_64, glibc 2.35 и новее: Ubuntu 22.04+, Debian 12+) | `ptt-radio-companion-<версия>-linux-x86_64.tar.gz` |

2. По желанию сверьте контрольную сумму с файлом `SHA256SUMS` из того же релиза: на Linux — `sha256sum --check --ignore-missing SHA256SUMS`, на macOS — `shasum -a 256 <файл>`.
3. Распакуйте архив в папку, куда у вас есть право записи, — иначе компаньон не сможет потом обновляться сам. Внутри одна программа, `ptt-radio-companion` (на Windows — `ptt-radio-companion.exe`), и файлы `LICENSE` и `README.md`.

Компаньон берите из того же релиза, что и мод. Компаньон другой версии мод не отвергает: раздел «Компаньон» в окне «Настройки рации» только сообщает, что компаньон устарел, новее мода или что версии совпадают. Компаньон без поддержки каналов рации вообще не может ни передавать, ни принимать голос; в этом случае окно показывает красную надпись «Обновите компаньон, чтобы пользоваться каналами рации. Этот компаньон не может ни передавать, ни принимать голос.» Первый запуск, клавиша рации и системные запросы разрешений описаны в разделе [Компаньон](RU-Companion).

## 3. Добавьте флаг запуска

Игра должна запускаться с `--enable-lua-udp 34556`. Именно на порту `34556` компаньон ищет игру по умолчанию (это его параметр `--game-port`). Если выберете другой порт, запускайте компаньон с `--game-port <тот же порт>`.

**Steam (Windows, macOS, Linux).**

1. В библиотеке Steam щёлкните по Factorio правой кнопкой и выберите «Свойства».
2. На вкладке «Общие» вставьте в поле «Параметры запуска» строку, которую установщик напечатал после `Steam launch options:`. Она выглядит так: `"<папка данных Factorio>/ptt-radio-companion/ptt-radio-companion" --launch %command%` (на Windows — с `.exe`). С ней компаньон запускается вместе с игрой и сам добавляет флаг Lua UDP. Если компаньон вы запускаете сами, впишите в это поле только `--enable-lua-udp 34556` вместо строки компаньона.
3. Закройте окно и запускайте игру как обычно.

**Версия с factorio.com.** Запускайте игру с флагом или допишите его в ярлык:

- Windows: `bin\x64\factorio.exe --enable-lua-udp 34556`, команду выполняйте в папке Factorio. В ярлыке на рабочем столе допишите флаг в конец поля «Объект».
- Linux: `./bin/x64/factorio --enable-lua-udp 34556`, команду выполняйте в папке Factorio.

**Приложение для macOS (не Steam).** В Терминале:

```sh
open -a factorio --args --enable-lua-udp 34556
```

Если Factorio уже запущена, сначала закройте её: `open` передаёт флаг только при новом запуске.

## 4. Проверьте

1. Выполните команду запуска, которую напечатал установщик, или запустите Factorio из Steam со строкой установщика, которую вы вписали в «Параметры запуска» на шаге 3 (см. [Компаньон](RU-Companion)).
2. Зайдите в сетевую игру.
3. Через несколько секунд в чате появится `Рация: компаньон подключён.`, а в окне компаньона — строка `roster:` со списком игроков.

Если сообщения нет, загляните в раздел [Если не работает](RU-Troubleshooting).
