# Настройка сервера

В итоге мод будет работать на вашем выделенном или арендованном сервере, вы будете знать, нужен ли серверу флаг Lua UDP, и какие настройки и инструменты администратора есть у владельца сервера.

## Что нужно серверу

- **Мод.** На сервере должен стоять `ptt-radio` той же версии, что у игроков. Мод решает, кто кого слышит, и показывает стопку говорящих; только на клиенте он работать не может.
- **Компаньон не нужен.** На сервере никто не слушает, так что ни компаньон, ни микрофон, ни звуковая карта ему не нужны.
- **`--enable-lua-udp` — только для хаба.** Голос игроков идёт внутри игры, поэтому серверу без хаба дополнительный флаг не нужен. Добавляйте `--enable-lua-udp <порт>` серверу, только если рядом с ним работает [хаб](RU-Hub): хаб общается с модом через этот порт.

## Мод на headless-сервере

1. Скачайте `ptt-radio_<версия>.zip` со [страницы релизов](https://github.com/vshuraeff/ptt-radio/releases).
2. Скопируйте архив как есть в папку `mods` сервера.
3. Включите мод: добавьте эту запись в список `mods` файла `mods/mod-list.json`.

   ```json
   { "name": "ptt-radio", "enabled": true }
   ```

4. Перезапустите сервер. Игрокам без мода игра предложит скачать его при подключении, если мод есть на портале; иначе пусть поставят его по разделу [Установка](RU-Installation).

С хабом команда запуска выглядит так (свои аргументы сейва и настроек оставьте):

```sh
./bin/x64/factorio --start-server <save.zip> --enable-lua-udp 34556
```

Пример для docker из раздела [Хаб](RU-Hub) (`docker/compose.example.yaml`) собирает сервер из `stand/server`. Его `server-settings.json` — тестовый профиль: сервер виден в локальной сети, проверка пользователей выключена, 4 игрока, автосохранение раз в минуту, администраторов нет. Для публичного сервера напишите свой `server-settings.json` (за основу возьмите `data/server-settings.example.json` из папки Factorio) и подключите его поверх тестового, добавив в `volumes` сервиса `factorio` строку:

```yaml
      - ./server-settings.json:/config/server-settings.json:ro
```

На арендованном сервере загрузите архив туда, куда панель хостинга кладёт моды, а флаг для хаба впишите в поле параметров запуска. Хабу нужен процесс или контейнер на той же машине, что и сервер, а многие хостинги такого не разрешают. Без хаба голос всё равно ходит через игру и напрямую между игроками.

## Настройки

**Настройка карты** (в игре: настройки модов, вкладка карты; менять могут только администраторы):

| Настройка | Значения | По умолчанию |
| --- | --- | --- |
| «Кто слышит рацию» | «Все», «Только своя команда» | «Все» |

Это внешняя граница для всех каналов: при «Только своя команда» игроки слышат только свою силу (force), какой бы канал ни выбрали.

**Настройки игрока** (каждый задаёт свои на вкладке игрока в настройках модов):

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| «Порт компаньона» | `34555` | UDP-порт на компьютере игрока, который слушает компаньон. |
| «Эхо своего голоса» | выкл. | Сервер возвращает игроку его голос, чтобы проверить связь в одиночку. |
| «Глушить эфир, пока говорю» | вкл. | Полудуплекс: пока игрок держит клавишу рации, других не слышно. |

## Администраторы

Политику рации задают администраторы сервера Factorio (`/promote <игрок>`):

- в разделе «Администрирование» внизу окна настроек рации (`ALT + SHIFT + V`);
- командой `/radio-admin` в чате. В консоли сервера та же команда пишется без косой черты: `radio-admin channel none`. У консоли права администратора.

Администратор может назначить обязательный админ-канал, запретить или закрепить каналы, заглушить игрока, закрыть ему канал, заблокировать его выбор или ограничить списком каналов. Политика хранится в сейве. Полный список команд — в разделе [Каналы и администрирование](RU-Channels-and-Admin).

Каналы определяют, что проигрывают честные клиенты, но разговор от посторонних не скрывают: голос получает каждая копия игры, так что сервер и изменённый клиент слышат всё.
