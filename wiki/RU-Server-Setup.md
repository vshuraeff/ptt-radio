# Настройка сервера

Пройдя эту страницу, вы запустите мод на своём выделенном или арендованном сервере, узнаете, нужен ли серверу флаг Lua UDP, и разберётесь, какими настройками и инструментами администратора распоряжается владелец сервера.

## Что нужно серверу

- **Мод.** На сервере должен стоять `ptt-radio` той же версии, что у игроков. Мод решает, кто кого слышит, и показывает список говорящих; только на клиенте он работать не может.
- **Компаньон не нужен.** На сервере никто не слушает, так что ни компаньон, ни микрофон, ни звуковая карта ему не нужны.
- **`--enable-lua-udp` — только для хаба.** Голос игроков идёт внутри игры, поэтому серверу без хаба дополнительный флаг не нужен. Добавляйте `--enable-lua-udp <порт>` в команду запуска сервера, только если рядом с ним работает [хаб](RU-Hub): хаб общается с модом через этот порт.

## Мод на headless-сервере

1. Скачайте `ptt-radio_<версия>.zip` со [страницы релизов](https://github.com/vshuraeff/ptt-radio/releases).
2. Скопируйте архив как есть в папку `mods` сервера.
3. Включите мод: добавьте эту запись в список `mods` файла `mods/mod-list.json`.

   ```json
   { "name": "ptt-radio", "enabled": true }
   ```

4. Перезапустите сервер. Игрокам без мода игра предложит скачать его при подключении, если мод есть на портале модов; иначе пусть поставят его по разделу [Установка](RU-Installation).

С хабом команда запуска выглядит так (аргументы со своим сохранением и настройками оставьте как есть):

```sh
./bin/x64/factorio --start-server <save.zip> --enable-lua-udp 34556
```

Пример для docker из раздела [Хаб](RU-Hub) (`docker/compose.example.yaml`) собирает сервер из `stand/server`. Его `server-settings.json` — тестовый профиль: сервер виден в локальной сети, проверка пользователей выключена, пароля на игру нет, 4 игрока, автосохранение раз в минуту, администраторов нет (как их добавить, см. [Администраторы](#администраторы)). Для публичного сервера напишите свой `server-settings.json` (за основу возьмите `data/server-settings.example.json` из папки Factorio) и подключите его поверх тестового, добавив в `volumes` сервиса `factorio` строку:

```yaml
      - ./server-settings.json:/config/server-settings.json:ro
```

Пока игра сохраняется или стоит на паузе, голос, который идёт через игру, замолкает; голос напрямую между игроками и через хаб продолжает идти. Когда игра продолжится, задержанные пакеты придут разом, но получатель отбросит накопившееся и закроет пропуски, так что застрявшая речь не прозвучит одним куском. Учитывайте это, когда выбираете интервал автосохранения.

На арендованном сервере загрузите архив туда, куда панель хостинга кладёт моды, а флаг для хаба впишите в поле параметров запуска. Хаб — это отдельный процесс или контейнер, и работать он должен на той же машине, что и сервер, а многие хостинги такого не разрешают. Без хаба голос всё равно ходит через игру и напрямую между игроками.

## Настройки

**Настройка карты** (в игре: «Настройки» → «Настройки модов» → вкладка «Карта»; менять её могут только администраторы):

| Настройка | Значения | По умолчанию |
| --- | --- | --- |
| «Кто слышит рацию» | «Все», «Только своя команда» | «Все» |

Эта настройка ограничивает все каналы сразу: при «Только своя команда» каждый слышит только игроков своей команды, какой бы канал ни выбрал.

**Настройки игрока** (каждый задаёт свои в «Настройках модов» на вкладке «Для каждого игрока»):

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| «Порт компаньона» | `34555` | UDP-порт на компьютере игрока, который слушает компаньон. Игра принимает значения от 1024 до 65535. |
| «Эхо своего голоса» | выкл. | Сервер возвращает игроку его же голос: так можно проверить связь в одиночку. |
| «Глушить эфир, пока говорю» | вкл. | Полудуплекс: пока игрок держит клавишу рации, других не слышно. При включённом открытом микрофоне настройка не действует. |

## Администраторы

Своего списка администраторов у мода нет: правила рации задают администраторы сервера Factorio, а консоли сервера это разрешено всегда. На свежем сервере из тестового профиля выше администраторов нет. Чтобы назначить администратора, впишите его имя в список администраторов сервера, файл `server-adminlist.json` (ключ `admins` в `server-settings.json` Factorio больше не читает), или выполните `/promote <игрок>` в консоли сервера (либо попросите об этом действующего администратора). Когда игрока делают администратором или снимают с него эти права, открытые окна рации сразу обновляются.

Администраторам доступны:

- раздел «Администрирование» внизу окна «Настройки рации» (`ALT + SHIFT + V`);
- команда `/radio-admin` в чате. В консоли сервера та же команда пишется без косой черты: `radio-admin channel none`. У консоли права администратора.

Администратор может назначить обязательный админ-канал, дать игроку право вещания на нём или отозвать это право (`publisher add|remove <игрок>`), запретить или закрепить каналы, заглушить игрока, запретить игроку канал, заблокировать его выбор или ограничить его списком каналов. Когда админ-канал назначен, его слышит каждый игрок с включённой рацией в пределах настройки «Кто слышит рацию», даже если не настраивался на этот канал; говорить на нём могут только администраторы и вещатели, остальные только слушают. Правила рации хранятся в сохранении карты. Полный список команд — в разделе [Каналы и администрирование](RU-Channels-and-Admin).

Каналы решают, что воспроизводят честные клиенты, но от чужих ушей разговор не скрывают: голос получает каждая копия игры, так что сервер и модифицированный клиент слышат всё.
